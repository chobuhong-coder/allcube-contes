⚠️ 이 페이지는 간단한 화면 잠금만 적용되어 있어요. Firebase 보안 규칙상 예약 데이터(bookings)는 누구나 읽을 수 있게 설정되어 있으므로,
진짜 보안이 필요하면 이 URL 자체를 외부에 공유하지 않는 방식으로 관리해주세요.
"상태"가 대기중(만료가능)으로 표시된 건 15분 홀드 시간이 지났지만 데이터가 아직 DB에 남아있는 예약이에요 — 슬롯 자체는 이미 재오픈된 상태입니다.
결제확인 체크박스는 실제 Firebase 데이터의 status 값을 confirmed로 바꿔서, 해당 시간대가 영구적으로 잠기도록(이중예약 방지) 만들어요. 체크 즉시 예약 위젯에도 반영돼요.
⚠️중복 표시는 같은 연락처로 미결제 예약이 여러 건 있다는 뜻이에요. 이땐 아임웹 주문 생성 시각과, 이 표의 "예약접수 시각" 중 가장 가까운 시각의 건이 실제 결제된 예약일 확률이 높아요 (고객은 보통 예약 직후 바로 결제 페이지로 넘어가기 때문).
"날짜/반" 열은 원데이클래스처럼 날짜기반 강의는 실제 날짜(YYYY-MM-DD)가, 정규반처럼 요일반 기반(rolling capacity) 강의는 "월요일반" 같은 반 이름이 표시돼요. 반 기반 강의는 특정 날짜가 아니라 그 반 자체에 정원이 걸려있어서 날짜 개념이 없어요.
"메모" 열은 예약자가 예약 시 남긴 선택 입력(예: 결제자와 예약자가 다른 경우 보호자/학생 이름)이에요. 김하준-김동주 케이스처럼 예약자와 결제자 이름이 다를 때 대조하는 용도로 쓰세요.
